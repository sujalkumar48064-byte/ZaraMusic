# Zara Music

Telegram voice-chat music bot built with Pyrogram and PyTgCalls.

## Setup

1. Copy `sample.env` to `.env` and fill the required values.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Start the bot:

```bash
python3 main.py
```

## Requirements

- Python 3.10+
- FFmpeg
- MongoDB (Atlas or local)
